Política de privacidad · PZF Subidas

PZF Subidas es una herramienta de uso personal que solo usa el propio autor para subir y programar sus vídeos en sus cuentas de YouTube e Instagram.

Datos que usa

Solo el permiso que el propio autor concede a su cuenta (subir vídeos y leer los datos básicos del canal). Ese permiso se guarda únicamente en su ordenador. No se recogen, venden ni comparten datos de otras personas.

Uso de los datos de Google

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Retirar el permiso

Se puede retirar en cualquier momento desde myaccount.google.com/permissions.
